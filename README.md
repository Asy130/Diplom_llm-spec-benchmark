# LLM Specification Benchmark

A benchmark for empirically evaluating the accuracy and effectiveness of
preconditions and postconditions generated by large language models (LLMs) on
game-themed Python tasks.

---

## Research Questions

**RQ1.** How accurately do LLM-generated specifications capture the behavioural
requirements expressed in natural language?

**RQ2.** How effectively do these specifications detect incorrect
implementations?

---

## What's Inside

- **40 game-themed Python tasks** with natural-language descriptions and
  formalized requirements.
- **Correct and faulty implementations** — hand-written and
  mutation-generated.
- **Two LLM-based specification-generation strategies**:
  - Strategy A — executable `assert` statements (preconditions, postconditions,
    invariants);
  - Strategy B — property-based tests built on `hypothesis`.
- **Executable specifications** — run via `pytest` without a verifier.
- **Hidden reference tests** — used only for evaluation; the LLM never sees
  them.
